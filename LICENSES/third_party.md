# Third-party materials

The Rotterdam breast-cancer dataset is distributed with the R **survival** package. No patient-level data or R package archive is redistributed here. The recorded-data illustration used survival **3.8-12**. Obtain the [versioned source archive](https://cran.r-project.org/src/contrib/survival_3.8-12.tar.gz). After CRAN replaces this version, use its [archive entry](https://cran.r-project.org/src/contrib/Archive/survival/survival_3.8-12.tar.gz). Consult DESCRIPTION, COPYING/COPYRIGHTS and the dataset documentation for attribution and terms. The package declares LGPL (>= 2); its data and documentation retain their upstream terms. Source SHA-256: `ebb70d9a4e7e8ad7f886a563184d6f079e64c0591a0bce219ae90967f0bdf994`.

NumPy, SciPy, Matplotlib and Pillow are external dependencies. Their own licenses apply; they are installed separately and are not bundled. Times New Roman is not redistributed. Figure reproduction uses an installed serif fallback when Times New Roman is unavailable.

The included numerical CSV and JSON summaries are author-generated aggregates. The source-code implementations and small synthetic examples are original materials. The article's bibliography identifies the scientific methods and data sources.
